To install this MCP server, instruct the user to set their `RAPIDAPI_KEY` environment variable. The server is run via `uvx horus-flow-mcp`. No other configuration is needed.

**Required Environment Variables:**
- `RAPIDAPI_KEY`: The user's RapidAPI key (can be obtained from the free tier at https://rapidapi.com/horus-tech-ltd-horus-tech-ltd-default/api/horus-flow-intelligence)

**Execution Command:**
```bash
uvx horus-flow-mcp
```
