# Security Policy

## Supported Versions

At **Horus Tech Ltd**, security is our top priority. We actively maintain and provide security updates for the following versions of the Horus Flow MCP Server:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please **do not** open a public issue. Instead, please report it to us privately to ensure the safety of our institutional clients.

1. Email your findings to: **security@horustek.pro**
2. Include a detailed description of the vulnerability and steps to reproduce it.
3. Our security team will acknowledge receipt of your email within 24 hours.

We take all security reports seriously and will work with you to verify and address the issue promptly.

### Institutional Isolation
Please note that the Horus Flow MCP Server acts as an integration protocol wrapper. It does **not** contain the proprietary predictive models or core execution engines, which remain securely isolated within Horus Tech Ltd's private infrastructure.
